# 审计日志 JSON 差异高亮设计

## 目标

在报价更新事件的“变更详情”中保留完整 JSON 上下文，并让用户快速识别旧值、新值及未变化内容。

## 展示规则

- 删除或被替换的旧值行使用浅红背景、深红文字和 `-` 前缀。
- 新增或替换后的新值行使用浅绿背景、深绿文字和 `+` 前缀。
- 未变化行维持现有中性等宽文本样式。
- 保留现有卡片、最大高度和滚动行为。
- 颜色之外同时使用 `-`、`+`，避免仅依赖颜色传达含义。

## 数据处理

- 只处理包含 `{ old, new }` 的审计变更值。
- 对对象和数组递归生成逐行 JSON 差异。
- 数组元素优先按位置比较，保留完整上下文。
- 不符合新旧值结构的数据继续使用现有 JSON 格式化逻辑。
- 不修改后端审计数据结构。

## 范围

- 修改 `AuditLogPage.vue` 的变更详情格式化与模板渲染。
- 为标量、对象和报价明细数组补充前端回归测试。
- 其他审计事件、筛选、导出及后端接口保持不变。

## 验收

- 修改报价时，旧值和新值分别显示红色 `-` 行与绿色 `+` 行。
- 未变化字段仍可见且保持中性样式。
- 长内容仍可在原卡片内滚动查看。
- 类型检查和相关前端测试通过。
